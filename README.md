# IndexedDB User Management UI

A responsive, Bootstrap 5-based user management interface with pure DOM manipulation. No backend, no database — just clean frontend UI code.

## 🖼️ Preview

The UI includes three main sections:
- **Add New User** — Form to create users (Full Name, Email, Role, Department)
- **Search Users** — Search and filter users by email or name
- **All Users** — Dynamic user list with Edit and Delete actions

## 🚀 Features

- ✅ Responsive design with Bootstrap 5
- ✅ Add, edit, and delete users (UI only)
- ✅ Search and filter users
- ✅ Toast-style notifications (success, warning, danger, info)
- ✅ Form validation with user feedback
- ✅ No external dependencies beyond Bootstrap CDN
